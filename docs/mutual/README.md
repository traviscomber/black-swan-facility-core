## Clasificación

Estado inicial: **Borrador controlado para revisión técnica y adecuación con Mutual de Seguridad**.

No se deben tratar como evidencia de cumplimiento los formularios vacíos, las capacitaciones no realizadas, las inspecciones no ejecutadas o los registros sin firma.

## Política de almacenamiento

Este repositorio de GitHub es público. Por esa razón, aquí solo deben mantenerse:

- índices documentales;
- plantillas sin datos personales;
- procedimientos técnicos no confidenciales;
- historial de versiones;
- instrucciones de publicación.

No se deben subir:

- documentos firmados;
- RUT, teléfonos privados o información sensible;
- nóminas laborales;
- certificados médicos;
- evidencia fotográfica identificable;
- investigaciones de accidentes;
- archivos con datos de huéspedes, trabajadores o contratistas.

Las versiones maestras DOCX, PDF, XLSX y ZIP deben almacenarse en un repositorio privado con autenticación, trazabilidad y respaldo.

## Control de cambios

Cada actualización debe indicar:

- código documental;
- versión;
- fecha;
- autor;
- revisor;
- motivo del cambio;
- estado de aprobación;
- ubicación de la versión maestra.
